# Wallet：錢包連接與網路檢查

## 責任與範圍

MVP 模組，提供連線、帳號、網路與可交易狀態。錢包連接不是學生身分驗證；本模組不管理名冊或保管金鑰。依賴與共用交易規則見[系統架構](../01-system-architecture.md)。

## 使用流程

1. 未連接時提供連接入口；無可用錢包時顯示指引。
2. 由學生選擇帳號並同意連接，顯示地址及目前網路。
3. 網路錯誤時提示切換 Sepolia；自動請求切換只能由明確操作觸發，失敗時提供手動指引。
4. 監聽帳號、網路、連線中斷事件，通知訂閱模組重新讀取或停用交易。
5. 提供斷開網站連線入口，說明錢包端連接權限可能需另外撤銷。

## 模組介面

輸出目前帳號、chain ID、連接狀態、是否允許交易及狀態事件；接受連接、切換網路、斷開請求。不持有其他模組交易表單；Token 等模組在送出前仍須重新確認帳號與網路。

MVP 先支援選定的瀏覽器錢包組合；多錢包發現、行動連線協定與相容性清單於 A-01 決策，不預先承諾品牌或套件。

## 錯誤與驗證

驗證無錢包、拒絕連接、拒絕切鏈、未知網路、鎖定／中斷、重複點擊與帳號切換。事件監聽在卸載時清理；切換後不得殘留前帳號資料或舊的可交易狀態。讀取教材不依賴連接成功。

## 後續與待決

多錢包進階管理與跨裝置連線延後。A-01 需決定套件、支援環境及事件處理方式；涉及共用 receipt 的策略由 A-05 負責。
