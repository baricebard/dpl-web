# Portfolio：投資組合檢視

## 責任與階段

未來模組，不屬於 MVP。將 Token 餘額與未來 Exchange／Liquidity 資料彙整為教學投資組合；MVP 的餘額列表仍屬 Token，不宣稱已具備估值或績效分析。

## 預期介面與資料邊界

輸入指定帳號、鏈、資產餘額、可選池權益與已定義價格資料；輸出持倉及有資料支持的教學統計。Portfolio 只讀取與計算，不代管資產或簽署交易。

畫面需標示計價單位、資料來源、更新時間與涵蓋範圍；缺少價格時仍可顯示數量，但不能將缺價視為零價。Sepolia ETH 若納入，需與教學 ERC-20 分開解釋。

## 尚未決定的估值（A-08）

- 計價單位與價格來源：教師設定、池報價或其他教學方法。
- 是否追蹤成本、現金流、歷史快照與績效，以及明確的計算方法。
- LP 權益如何估值及避免與直接持倉重複計算。
- 無資料庫／索引服務時可提供的歷史範圍、本機保存與匯出需求。

不得以代幣數量直接相加當作總價值，也不得宣稱美元價值或真實投資收益。完整交易歷史若需索引服務，應先修訂依賴與資料架構。

## 未來驗證

以固定資料集驗證單位、精度、價格缺失／過期、帳號切換、LP 重複計值及所選績效公式。不同來源更新時間需可辨識，讀取失敗不得生成誤導的資產下降曲線。
