# Layer 2：擴容與鏈下交易概念

## 責任與階段

未來模組，不屬於 MVP。透過教材或獨立實驗比較 Layer 1、Layer 2 與鏈下交易概念，不將 Sepolia ERC-20 轉帳稱為 Layer 2 交易。

## 教學邊界與介面

教材應區分執行、資料可用性、結算、最終性，以及鏈下簽署與鏈上交易的差異。單純瀏覽器內模擬不代表鏈上結算；單純鏈下訊息也不等同 Layer 2。

概念模式輸入為教學情境，輸出比較與模擬結果，必須明確標示模擬。若未來加入測試網實驗，需輸入獨立網路／資產設定並提供對應 Wallet 與交易狀態，不沿用 Sepolia 合約地址。

## 尚未決定的範圍（A-09）

是否只提供教材、是否加入鏈下簽署或 Layer 2 測試網操作、選擇哪個網路、是否需要橋接及額外資源皆待決。初期不部署 Layer 2、不建置 rollup、不實作橋接。增加任何跨鏈操作需另列信任假設、驗收條件與資源準備，不屬於既有 MVP。

## 未來驗證

檢查教材用語與資料來源，確保模擬與實際交易標示清楚。若加入實驗，另外測試網路誤用、資產地址隔離、簽署訊息的用途與重放防護，以及所選網路的最終性與故障情境。
