# Faucet：測試資源取得

## 責任與範圍

MVP 提供 Sepolia ETH 外部領取指引及三種教學代幣取得說明，不承諾網站一鍵領幣。Sepolia ETH 與 ERC-20 代幣是兩條不同供給流程；發放 ERC-20 不能替學生支付 Gas。

## MVP 使用流程

1. 說明 Gas 用途，引導確認 Sepolia 收款地址。
2. 提供經教師課前查核的外部 Faucet 連結、操作步驟與資格限制；網址與服務可用性不得寫成永久保證。
3. 教學代幣按選定方式由教師分發或依其他已驗證流程取得；正式授課前需補齊可執行說明，目前方式尚未定案。
4. 領取後由 Token 重新讀取餘額；本模組不以外部網頁的成功訊息保證入帳。

## 模組介面與限制

輸入公開網路／資源連結設定及可選的 Wallet 地址，輸出教材、外部連結與刷新餘額入口。不接受私鑰，不自動代簽，不依賴網站伺服器持有發幣權限。未連接者亦可閱讀指引；地址複製需有明確操作與回饋。

## 驗證與課堂處置

檢查外部連結、網路標示及地址複製；演練服務離線、資格不足、額度用盡、領取未入帳及 Gas 不足。教師於課前確認 30 人供給與替代分發方式；不得承諾無限制或立即領取。

## 後續與待決

A-04 需決定教學代幣分發方式、每次額度、冷卻時間、管理角色及濫用限制。若採鏈上 Faucet，先定義合約餘額不足、暫停、重複領取與權限測試；前端限制無法防止直接呼叫合約。學生名冊驗證或受保護配額若需要後端，必須另訂架構範圍。一鍵領取與專用 Faucet 合約皆延後，不是 MVP 必要機制。
